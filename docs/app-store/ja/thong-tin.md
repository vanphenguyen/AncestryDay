## Description (Mô tả)

Nơi nhập: trang phiên bản.

```
大切な人の日を、忘れないために。

AncestryDay は、ご家族のご命日帳です。一度登録すれば、毎年のご命日を一週間前・前日・当日にお知らせします。一周忌、三回忌、七回忌などの年忌も自動で表示します。

主な機能
• ご命日帳(新暦・旧暦のどちらでも登録可能)
• 年忌を自動で計算
• 7日前・3日前・前日・当日のお知らせ
• 春と秋のお彼岸、お盆のお知らせ
• 月の満ち欠けつきの旧暦カレンダー
• 旧暦は国ごとの違い(日本・中国・韓国・ベトナム)に対応し、日付が食い違う年はお知らせします
• 日本語、English、中文、한국어、Tiếng Việt

プライバシー
アカウント不要、通信なし、データ収集なし。すべて端末の中だけに保存されます。
```
