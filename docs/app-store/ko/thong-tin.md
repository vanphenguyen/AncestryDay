
## Description (Mô tả)

Nơi nhập: trang phiên bản.

```
사랑하는 이의 날을 잊지 않도록.

기일은 음력으로 지내지만 일상은 양력으로 흘러갑니다. 해마다 날짜가 달라져 미처 준비하지 못하는 일이 생깁니다.

AncestryDay 는 가족의 기일 수첩입니다. 한 번만 등록하면 해마다 양력 날짜를 계산해 일주일 전, 하루 전, 당일에 알려 드립니다.

한국 음력으로 정확하게
한국, 중국, 베트남의 음력은 나라마다 자기 시간대로 계산해 가끔 하루, 드물게는 한 달씩 차이가 납니다. 휴대폰 기본 음력은 대개 중국식입니다. 이 앱은 한국 음력으로 계산하고, 달력이 서로 다른 해에는 알려 드립니다.

주요 기능
• 가족 기일 수첩 (음력·양력)
• 몇 주기인지 자동 계산
• 양력 날짜만 알아도 음력으로 변환
• 7일 전, 3일 전, 하루 전, 당일 알림
• 설날, 한식, 추석 알림
• 달 모양이 있는 음력 달력
• 한국어, English, 中文, 日本語, Tiếng Việt

개인정보
계정 없음, 인터넷 불필요, 수집하는 정보 없음. 모든 내용은 휴대폰에만 저장됩니다.
```
